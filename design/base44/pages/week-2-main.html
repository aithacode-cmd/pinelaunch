Steps

  1. 15 pts
    What to do
    • Create one project in Replit or Base44. Not both.
    • Name the project with your project name. Keep it lowercase and hyphenated.
    • Get a parent's permission before you make an account if you do not already have one.
    How to know it is done

    You can open your project in the browser and see a blank running app.

    If you are stuck

    Use the template your tool suggests and delete what you do not need. An empty page that runs is enough for today.

  2. 20 pts
    What to do
    • Build only feature one. Nothing else exists yet.
    • Use the week two prompts when you are unsure. Ask for hints, not a finished file.
    • When it works once, stop and tick this step. Do not start styling it.
    How to know it is done

    One person can complete feature one in your project without help.

    If you are stuck

    Describe what you see and what you expected to ChatGPT, paste the smallest piece of code involved, and ask for one next step. Change one thing at a time.

    Locked example

    Example · One feature at a time opens after you try this step yourself. No answer is checked or sent anywhere.

    0 of 2 sentences
  3. 20 pts
    What to do
    • Add feature two to the version that already works.
    • Test feature one again after the change. Old things break easily.
    • If feature two needs feature one to change, change as little as possible.
    How to know it is done

    Both features work in the same session, in any order.

    If you are stuck

    Write down the last change that worked. Undo until the project runs again, then redo the change in smaller pieces.

  4. 20 pts
    What to do
    • Add the third feature and nothing more.
    • Make it as plain as possible. Correct first, good-looking second.
    • Check on a phone-sized window, not only on your laptop.
    How to know it is done

    All three features work and the page does not scroll sideways on a phone.

    If you are stuck

    If the third feature is fighting you, make the first version with two features. Two working features beat three broken ones.

  5. 10 pts
    What to do
    • Write down every bug you can find. There is no need to fix them all.
    • Pick the one that stops the main job from working.
    • Fix that one. If it survives the fix, write it in Discord and ask for a hint.
    How to know it is done

    The main job works again and you can say what you changed.

    If you are stuck

    Read the error message from the top, not the bottom. The first line usually names the file and the line.

  6. 10 pts
    What to do
    • Show the project to one person. Say nothing and let them try.
    • Write down where they paused or asked a question.
    • Do not fix anything during the session. Notes only.
    How to know it is done

    You have at least two written notes from someone who is not you.

    If you are stuck

    If nobody is free, a parent counts. Five minutes is enough.

Prompts for this week

Hints and small steps only

Copy a prompt into ChatGPT and paste your Project Card details where the brackets are. Every prompt ends with the same instruction: do not write the code for me.

Start the first screen 
I am a high school student building my project, a small app for one person I know, using my build tool. The first feature I need is: my first feature.Explain how this kind of screen is usually put together, in plain words and short numbered steps. Tell me what to build first and what to leave out. Give me hints and small steps only, and do not write the code for me.
Understand an error message 
I am building my project in my build tool. My project stopped working and this is the message I see:[paste the full message here]Explain what the message means in plain words, where I should look first, and one change I can try. Then give me a way to test it. Do not write the code for me.
Add a feature without breaking the rest 
My project my project works and already does: my first feature and my second feature. I want to add my third feature without breaking what works.List the smallest possible steps to add it, in order, and tell me what to test after each step. Warning me about the two things most likely to break is enough. Do not write the code for me.

That is a finding, not a failure. Write down the exact question they asked. It becomes your one fix for week three.
