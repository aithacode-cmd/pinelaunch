Week 03

Launch

Dec 14 to 20

Get three people to try it, fix one thing, and publish a link.

Complete0%
0 of 5 steps · 0 pts

Steps

  1. 20 pts
    What to do
    • Ask three people who are not you. Family, classmates, teammates.
    • Send the link and the one sentence about who it is for.
    • Ask for five minutes, not for feedback in general.
    How to know it is done

    Three people have opened your project.

    If you are stuck

    One person repeated three times still counts as one tester. Ask a different age if you can. A younger sibling is a good tester.

  2. 15 pts
    What to do
    • Let them use it without your instructions.
    • Write down every pause, question, and wrong turn.
    • Keep your hands off the keyboard. Notes only.
    How to know it is done

    You have a short list of real moments, not opinions.

    If you are stuck

    If you cannot watch in person, ask one question: what did you expect to happen when you pressed that?

  3. 15 pts
    What to do
    • Choose one problem that appeared more than once, or blocked the main job.
    • Fix only that. Resist the other notes for now.
    • Test the fix with the same person if you can.
    How to know it is done

    The same problem does not happen again in a fresh test.

    If you are stuck

    Choose the fix that takes under an hour. If it takes longer, the problem is bigger than this week allows.

    Locked example

    Example · One fix, chosen well opens after you try this step yourself. No answer is checked or sent anywhere.

    0 of 2 sentences
  4. 20 pts
    What to do
    • Use your tool's publish button. Replit and Base44 both produce a public link.
    • Open the link in a private window. If it loads without signing in, it is public.
    • Write the link down somewhere you will not lose it.
    How to know it is done

    The link opens in a private window and shows your project.

    If you are stuck

    If the link asks people to sign in, it is not published yet. Look for Publish or Deploy, not Share.

  5. 15 pts
    What to do
    • Post in the launch channel: the name, the one sentence, and the link.
    • Say who it is for and what you fixed after testing.
    • Submit the week three form.
    How to know it is done

    Your post is in Discord with a working link.

    If you are stuck

    Keep the post to four lines. Nobody needs the story of the build in the channel.

Prompts for this week

Hints and small steps only

Copy a prompt into ChatGPT and paste your Project Card details where the brackets are. Every prompt ends with the same instruction: do not write the code for me.

Turn notes into one fix
My project my project was tested by three people. Their notes: [paste the notes here].

Help me choose the single fix worth making this week. Rank the notes by how much they block the main job, explain your choice in three sentences, then give me the smallest steps to make that change. Do not write the code for me.
Rewrite the instructions on the page
My project my project is a small app for one person I know. Testers could not tell what to do first.

Write three short versions of an instruction line for the top of the page. Each one must be under twelve words, avoid jargon, and tell the person exactly what to do first. Explain which one you would pick. Do not write the code for me.
Write the launch post
I am posting my finished project in a small private Discord for a school program. Details: name my project, type app, for one person I know, one job one small job, link [paste your link].

Write a four-line post with no hype, no emoji, and no exclamation marks. Then write a second version that is even shorter. Do not write the code for me.

Common problems

My link only works on my computer

That means it is still running locally. Find the publish or deploy control in your tool and use it. Then open the new link in a private window to check.

Testers did not reply

Ask one person at a time with a direct link. A group message is easy to ignore. Five minutes in person works better than a message.

I have too many fixes and one day left

Fix the one that blocks the main job. Everything else goes in the later list, which you can keep after the program ends.

The final version looks unfinished

A plain project that works is a finished project. Leave the styling for after launch day.
