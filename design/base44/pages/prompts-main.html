Prompts

Every prompt, in one place.

Copy a prompt into ChatGPT. Your Project Card details are filled in where the prompt asks for them. Each one asks for hints and small steps, and says do not write the code for me.

Week 1 · Idea

3 prompts
Narrow the idea 
I am a high school student in a three-week program. I am building a small app called my project for one person I know. The one job it should do: one small job.Ask me five short questions that would make this project smaller and clearer. Then give me three next steps, one at a time. Keep every answer under six lines, use plain words, and do not write the code for me.
Cut it down to three features 
My project is my project, a small app for one person I know. I have these feature ideas: my first feature, my second feature, my third feature, and some extras I have not listed yet.Help me cut this down to three features for a first version. Ask me what my one person actually needs, explain what you would drop and why, then give me the three features as short task-sized steps. Do not write the code for me.
Write the one-sentence pitch 
My project: my project, a small app for one person I know. The one job it does: one small job.Write five different one-sentence versions of this pitch. Each must say who it is for and what it does, with no hype and no adjectives that cannot be checked. Tell me which one is clearest and why. Do not write the code for me.

Week 2 · Build

3 prompts
Start the first screen 
I am a high school student building my project, a small app for one person I know, using my build tool. The first feature I need is: my first feature.Explain how this kind of screen is usually put together, in plain words and short numbered steps. Tell me what to build first and what to leave out. Give me hints and small steps only, and do not write the code for me.
Understand an error message 
I am building my project in my build tool. My project stopped working and this is the message I see:[paste the full message here]Explain what the message means in plain words, where I should look first, and one change I can try. Then give me a way to test it. Do not write the code for me.
Add a feature without breaking the rest 
My project my project works and already does: my first feature and my second feature. I want to add my third feature without breaking what works.List the smallest possible steps to add it, in order, and tell me what to test after each step. Warning me about the two things most likely to break is enough. Do not write the code for me.

Week 3 · Launch

3 prompts
Turn notes into one fix 
My project my project was tested by three people. Their notes: [paste the notes here].Help me choose the single fix worth making this week. Rank the notes by how much they block the main job, explain your choice in three sentences, then give me the smallest steps to make that change. Do not write the code for me.
Rewrite the instructions on the page 
My project my project is a small app for one person I know. Testers could not tell what to do first.Write three short versions of an instruction line for the top of the page. Each one must be under twelve words, avoid jargon, and tell the person exactly what to do first. Explain which one you would pick. Do not write the code for me.
Write the launch post 
I am posting my finished project in a small private Discord for a school program. Details: name my project, type app, for one person I know, one job one small job, link [paste your link].Write a four-line post with no hype, no emoji, and no exclamation marks. Then write a second version that is even shorter. Do not write the code for me.
